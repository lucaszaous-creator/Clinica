Como a tela ficou. Reprodução em HTML do XAML entregue — não é um screenshot: o app é WPF e só compila no Windows. Cada valor abaixo foi lido de Styles/Pilot/Tokens.xaml e a estrutura de Views/ConsultaGuiasView.xaml; os comentários do CSS dizem qual token governa cada regra.
  • O que pode sair diferente na sua máquina: o desenho da fonte. O app usa Segoe UI Variable (Windows 11) e cai para Segoe UI no Windows 10. Geometria, cor, peso e espaçamento são os mesmos.
  • Os dados são de exemplo, mas os CAMPOS e os estados são os reais: este módulo não tem dinheiro — “baixa” é a guia efetivada no portal do convênio, e os estados são Aberto · Baixado · Não aplicável, com a glosa em coluna própria.
  • Só esta tela mudou. O dicionário do piloto não está no App.xaml: as outras doze telas do faturamento continuam exatamente como estavam.
